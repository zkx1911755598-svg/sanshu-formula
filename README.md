# 数三公式 · 随机背

一个按“背单词”方式随机背诵考研数学三公式的 iPhone 网页 App。苹果原生风格，按艾宾浩斯遗忘曲线安排复习，支持离线、收藏、难题本和进度统计。

## 文件

- `index.html`：完整 App（KaTeX 与字体全部内嵌，单文件约 740 KB）
- `manifest.webmanifest`、`sw.js`：添加到主屏幕与离线缓存
- `icon-180.png`、`icon-192.png`、`icon-512.png`：主屏幕图标

## 在 iPhone 上使用

推荐把整个 `outputs` 文件夹放到任意静态托管上，然后用 Safari 打开链接。

### 方式一：GitHub Pages

1. 在 GitHub 新建一个仓库（Public 即可）。
2. 把 `outputs` 里的所有文件上传到仓库根目录。
3. 进入仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存。
4. 等 1–2 分钟，打开 `https://你的用户名.github.io/仓库名/`。
5. Safari 中点底部分享按钮 → **添加到主屏幕**。

### 方式二：Netlify Drop / Vercel

把 `outputs` 文件夹拖进 Netlify Drop，或导入 Vercel 新建静态项目。部署完成后同样用 Safari 打开并“添加到主屏幕”。

### 只在本机看

在 `outputs` 目录运行任意静态服务器：

```bash
python -m http.server 8000
```

电脑和 iPhone 连同一个 Wi-Fi，iPhone 访问 `http://电脑局域网IP:8000`。这样可以正常使用全部功能；但 Service Worker 的离线缓存需要 HTTPS，正式使用建议用上面的托管方式。

## 怎么背

- **今天**：显示待复习数量、今日新卡配额和连续天数，点“开始背诵”。
- **背卡**：先看标题和问题，轻点卡片翻到公式；按“忘了 / 模糊 / 会了”反馈。
- **艾宾浩斯节奏**：1 分钟 → 5 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天 → 60 天 → 120 天。答“会了”前进一阶，“模糊”退一阶，“忘了”回到 1 分钟；进入 15 天阶段记为“已掌握”。
- **章节**：按微积分 / 线性代数 / 概率统计抽背，也可以只刷收藏、难题或随机 20 张。
- **收藏**：背卡右上角星标收藏，小旗加入难题本。
- **统计**：今日复习量、正确率、近 7 天柱状图、各章掌握度、最容易忘的公式。
- **设置**：每日新卡数、深浅色、公式字号、导出/导入 JSON 备份、重置进度。

所有进度只存在当前浏览器本地，不需要账号，也不会上传。换手机或清理 Safari 数据前，先在“设置 → 导出备份”保存 JSON。

## 复习算法

每张卡片记录当前所处的记忆阶段、上次复习时间和复习次数。系统用遗忘曲线 `R(t)=exp(-t/τ)` 估算当前保持率，其中 τ 取“到期时保持率为 90%”对应的值。到期卡片按保持率从低到高排序，先背最容易忘的。

- **会了**：前进一阶，按新阶段安排下次复习。
- **模糊**：退一阶，缩短间隔。
- **忘了**：回到 1 分钟阶段，并计入薄弱公式。
- **1 分钟 / 5 分钟阶段**：会在当前这一组里再次出现，完成短时巩固；30 分钟以后按到期时间安排。

首页会显示完整的复习阶梯；背卡页会显示“第几阶、当前阶段间隔、预测保持率”。

## 题库

共 195 张，按数三常见考点整理：

| 章节 | 数量 | 主要内容 |
| --- | ---: | --- |
| 微积分 | 107 | 极限、连续、导数、中值定理、积分、多元微分、二重积分、级数、微分方程、差分方程 |
| 线性代数 | 42 | 行列式、矩阵、向量组、方程组、特征值、相似、二次型 |
| 概率统计 | 46 | 概率计算、常见分布、二维随机变量、数字特征、极限定理、抽样分布、参数估计 |

每张卡包含：公式、适用条件、易错提醒。范围按数三整理，未收录数一/数二专属的曲率、弧长、三重积分、曲线曲面积分、傅里叶级数等内容。建议对照当年的考试大纲使用。

## 修改题库

源文件在 `work/app/`：

- `cards-j.js`（微积分）、`cards-x.js`（线代）、`cards-g.js`（概率）
- 每行一张卡：`id§章节§小节§标题§问题§LaTeX 公式§适用条件§易错提醒`
- 适用条件/提醒里可以用 `$...$` 写行内公式

改完运行：

```bash
node work/app/build.js
```

会重新生成 `outputs/index.html`。
